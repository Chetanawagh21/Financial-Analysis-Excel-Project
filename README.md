# Financial Sales Performance Dashboard – Excel Project

## Project Overview
This project focuses on analyzing financial sales data using Microsoft Excel. The dashboard provides insights into sales performance, profit, discounts, products, countries, and business segments.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Charts and Data Visualization
- Financial Data Analysis

## Project Objectives
- Analyze sales and profit performance.
- Compare financial performance across countries and products.
- Evaluate discounts and their relationship with profit.
- Analyze yearly sales trends.
- Present key financial insights through an interactive-style dashboard.

## Workbook Contents
- **Financial data:** Source financial dataset.
- **Dashboard:** Financial Sales Performance Dashboard.
- **PS1:** Profit analysis by product and business segment.
- **PS2:** Sales analysis by country and year.
- **PS3:** Discount and profit analysis by product.
- **PS4:** Year-wise sales summary.

## Skills Demonstrated
Data Analysis | Microsoft Excel | Pivot Tables | Data Visualization | Dashboard Creation | Business Reporting

## Project Files
`Project Financial Sample.xlsx` – Excel workbook containing the financial dataset, analysis sheets, and dashboard.

## Key Learning
This project helped develop practical skills in financial data analysis, summarizing business data, comparing performance metrics, and presenting insights using Excel.
